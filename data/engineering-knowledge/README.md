# 土木、建築與鋼材專業知識索引

此索引整理水土保持、大地工程、土木結構、鋼材、施工品質與水利等官方來源，包含 20 筆知識卡及跨領域關聯。資料整理日期見 index.json，每筆附原始網址、提供單位、類型及檢視日期。摘要為原創的導航及技術背景，並非逐條法規、個案設計、技師簽證或來源全文。

助理搜尋使用知識卡標題、關鍵字、摘要與關聯，並提供可點擊的官方來源。每日鋼市研究僅在議題相關時使用來源線索，須重新搜尋並核實原文、發布時間與資料適用範圍；歷史資料不可當即時行情、法規或設計標準。圖資為區域查詢，不代替基地鑽探、現地查核及主管機關認定。

維護：更新 index.json 後執行 `python3 scripts/build_reference_search.py` 重建助理索引；確認來源頁可用與版本，再執行 `node tests/reference-search.test.js`。專業標準及法規可能更新，應定期由具備相關專業的人員複核。
